DNS Tester

Repositorios Flatpak oficiales — instala la versión beta (develop) para probar lo último o stable (main) para producción. Repos firmados con GPG, servidos en GitHub Pages.

★ GitHub Releases

🧪 Beta develop

Canal de pruebas. Se actualiza en cada push a develop y en cada pre-release (YY.MM.DD.hhmm). Ideal para probar nuevos proveedores y correcciones.

https://neikon.github.io/dns_tester/beta/

Instalación (recomendado --user en Silverblue)

flatpak --user remote-add --if-not-exists dns_tester-beta \
  https://neikon.github.io/dns_tester/beta/dns_tester.flatpakrepo
flatpak --user install dns_tester-beta es.neikon.dns_tester
# o system-wide:
# flatpak remote-add --if-not-exists dns_tester-beta https://neikon.github.io/dns_tester/beta/dns_tester.flatpakrepo
📄 dns_tester.flatpakrepo 📦 dns_tester.flatpak 📁 repo

✅ Stable main

Canal estable. Se actualiza solo al mergear a main (release). Firmado con la misma clave GPG que beta, pero con rama OSTree stable.

https://neikon.github.io/dns_tester/stable/

Instalación

flatpak --user remote-add --if-not-exists dns_tester-stable \
  https://neikon.github.io/dns_tester/stable/dns_tester.flatpakrepo
flatpak --user install dns_tester-stable es.neikon.dns_tester
📄 dns_tester.flatpakrepo 📦 dns_tester.flatpak 📁 repo
¿Error ConfigureRemote not allowed for user? Es normal en Fedora Silverblue/Kinoite sin privilegios. Usa siempre --user como en los ejemplos. Los repos están firmados con GPG (DNS Tester Flatpak <flatpak@neikon.es>, RSA 2048) — no necesitas --no-gpg-verify.
Instalación directa sin repositorio: también puedes instalar el bundle suelto sin añadir el remoto: 
flatpak --user install --bundle https://neikon.github.io/dns_tester/beta/dns_tester.flatpak
flatpak --user install --bundle https://neikon.github.io/dns_tester/stable/dns_tester.flatpak
