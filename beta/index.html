DNS Tester Beta Flatpak Repository

URL: https://neikon.github.io/dns_tester/beta/

Add remote (unsigned repo, use --no-gpg-verify):

flatpak remote-add --if-not-exists --no-gpg-verify dns_tester-beta https://neikon.github.io/dns_tester/beta/dns_tester.flatpakrepo
flatpak install dns_tester-beta es.neikon.dns_tester

Alternative direct bundle:

flatpak install --bundle https://neikon.github.io/dns_tester/beta/dns_tester.flatpak
