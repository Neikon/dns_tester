DNS Tester Stable Flatpak Repository

URL: https://neikon.github.io/dns_tester/stable/

Add remote (signed repo, use --user if system operation not allowed):

flatpak remote-add --if-not-exists dns_tester-stable https://neikon.github.io/dns_tester/stable/dns_tester.flatpakrepo
flatpak install dns_tester-stable es.neikon.dns_tester
# or per-user on Silverblue/Kinoite:
flatpak --user remote-add --if-not-exists dns_tester-stable https://neikon.github.io/dns_tester/stable/dns_tester.flatpakrepo
flatpak --user install dns_tester-stable es.neikon.dns_tester

Alternative direct bundle:

flatpak install --bundle https://neikon.github.io/dns_tester/stable/dns_tester.flatpak
flatpak --user install --bundle https://neikon.github.io/dns_tester/stable/dns_tester.flatpak
